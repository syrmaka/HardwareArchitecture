| Параметр | HDD | SSD |
| :--- | :--- | :--- |
| **Принцип работы** | Магнитная запись на вращающиеся диски с помощью считывающей головки | Хранение данных в микрочипах флеш-памяти (NAND). Нет движущихся частей |
| **Скорость чтения/записи** | 100–200 МБ/с | 500–7000+ МБ/с |
| **Наличие движущихся частей** | Да | Нет |
| **Устойчивость к ударам** | Низкая | Высокая |
| **Уровень шума** | Слышен гул вращения и треск головок | Работает бесшумно |
| **Цена за 1 ТБ** | Низкая | Высокая |
| **Срок службы/ограничения** | Ограничен механическим износом. Чувствителен к вибрациям | Ограничен количеством циклов перезаписи (ресурс TBW). При поломке восстановить данные сложно |
| **Пример использования** | Архивы, файлопомойки, видеонаблюдение, бюджетные ПК, NAS | Операционная система, программы, игры, рабочие станции, ноутбуки |


1. **DDR (Double Data Rate)** — тип памяти, который передает данные в два раза быстрее обычного.
2. **DIMM** — это сама планка оперативной памяти, которую ты вставляешь в компьютер.
3. **Ранг (rank)** — это «этаж» или группа чипов на планке. Компьютер обращается к ним не по одному, а целой группой за раз.
4. **CAS Latency (CL)** — показывает задержку перед тем, как память выдаст запрошенные данные. Чем меньше число — тем быстрее отклик.
5. **Тайминги** — это набор задержек, которые описывают, сколько времени памяти нужно на выполнение разных операций. Чем ниже — тем быстрее.
6. **Двухканальный режим** — нужен, чтобы увеличить скорость работы памяти за счет параллельной работы двух планок.
